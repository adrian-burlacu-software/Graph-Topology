# V687 interactive reasoner.
#
#   pip install -r research/v687/requirements.txt
#   python -m spacy download en_core_web_sm
#   python -m spacy download en_core_web_trf
#
# The server and reasoner are stdlib-only. spaCy is used for question parsing
# and lemmatisation; without it V687 falls back to a regex parser and says so
# in the UI, so the demo still runs on a bare interpreter.
spacy>=3.7

# WordNet sense keys. `research/v688/audit.py` resolves XCSLB's shipped
# `sensekey` column to a synset -- `donkey%1:05:00::` is `domestic_ass.n.01` --
# for the `pinned` configuration. Needs the corpus too:
#
#   python -c "import nltk; nltk.download('wordnet')"
nltk>=3.8

# spaCy on the GPU. Every layer reads with one shared model
# (`research/v687/language.load`): the transformer, en_core_web_trf, on the GPU
# where there is one. thinc needs CuPy for that, and `[ctk]` brings the CUDA
# libraries it loads (cuBLAS and the rest), so no system CUDA toolkit is needed.
# Built for CUDA 12; without a GPU or without this, the model runs on the CPU,
# and `SPACY_GPU=0` keeps it there anyway.
cupy-cuda12x[ctk]>=14; platform_system != "Darwin"
