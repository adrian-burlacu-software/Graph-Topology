# V130 Cognitive Architecture

Whole-system evaluation of:
- ConceptNet-backed long-term semantic memory
- transient modular attention over that memory
- temporary working-memory graph
- graph designer: REUSE / CREATE / BRANCH / INHIBIT / BIND / ACCUMULATE
- 24 short language episodes

Run from `research/`:

```powershell
python .\v130_cognitive_architecture\integrated_eval.py
```

Outputs:
- `results/v130_cognitive_architecture_report.json`
- `results/v130_long_term_memory.json`

The test suite is intentionally small and whole-system oriented.
